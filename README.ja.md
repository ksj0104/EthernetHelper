# EthernetHelper — 初めての方向けガイド

[言語を選ぶ](README.md) · [한국어](README.ko.md) · [English](README.en.md)

## 1. どんなアプリですか？

Windowsパソコンを**LANケーブルで接続しているのにインターネットが使えない**とき、接続を調べるアプリです。対応できる問題が見つかると修復を試せます。

起動すると、まず診断します。**診断だけではネットワーク設定は変わりません。** 修復ボタンを押すと設定変更を試みます。

- Windows 10 / 11向けです。Macやスマートフォンでは動作しません。実機確認はWindows 10の64ビット版で行っており、Windows 11は追加検証が必要です。
- Wi-Fiの修復用ではありません。有線接続が対象です。
- インストールやプログラミングの知識は不要です。WindowsのPowerShell 5.1と.NET Framework 4.xを使用します。
- ダウンロードできなければ、別のパソコンでZIPを取得し、USBメモリーで移してください。
- **アプリの画面は韓国語です。** ガイドには実際のボタン名と訳を記載しています。ガイドの言語を変えてもアプリの表示言語は変わりません。

## 2. ダウンロードする

**v1.0.1でダウンロード後の起動エラー（終了コード1）を修正しました。** 古いアプリを閉じ、最新ZIPを新しいフォルダーに展開してください。アプリ内部のスクリプト実行のためにZIPのブロックを手動解除する必要はなくなりました。下記の解除手順は任意です。Windowsの発行元警告や組織のポリシーは引き続き適用されます。

1. **[Windows用ZIPをダウンロード](https://raw.githubusercontent.com/ksj0104/EthernetHelper/master/downloads/EthernetHelper-Windows.zip)**をクリックします。GitHubへのログインは不要です。
2. 完了まで待ちます。ZIPとは複数のファイルをまとめた圧縮ファイルです。
3. **Windowsキー + E**でエクスプローラーを開き、**ダウンロード**を選びます。
4. `EthernetHelper-Windows.zip`を探します。末尾の`.zip`は表示されない場合があります。

GitHubのCodeメニューや個別のソースファイルは必要ありません。

## 3. ZIPを展開する

1. ZIPを右クリックし、**プロパティ**を開きます。
2. **全般**タブの下にブロック解除の項目（**許可する**など）があればチェックし、**適用 → OK**を押します。なければそのまま進みます。
3. ZIPをもう一度右クリックし、**すべて展開**を選びます。
4. 保存先はそのままで**展開**を押します。
5. 開いたフォルダーで次のファイルを確認します。

| ファイル | 役割 | 操作 |
| --- | --- | --- |
| `EthernetHelper.exe` | アプリ本体 | ダブルクリックで起動 |
| `Engine.ps1` | 診断・修復に必要 | EXEと同じフォルダーに置く |
| `README`で始まるファイル | 各言語の説明書 | 必要に応じて読む |

**ZIPの中から直接起動せず、先に展開してください。** `Engine.ps1`を自分で実行する必要はありません。EXEだけを別の場所に移動しないでください。

## 4. 起動して診断する

1. 展開したフォルダーの**EthernetHelper.exe**をダブルクリックします。名前は`EthernetHelper`と表示される場合もあります。
2. 自動診断が終わるまで待ちます。
3. 候補が複数ある場合、LANケーブルをつないでいるアダプターを選びます。アダプターはPCをネットワークにつなぐ機器です。分からない場合は詳しい人に確認してください。
4. 再度確認するには**진단하기**を押します。
5. 結果を確認します。正常であれば修復は不要です。

| 画面のボタン名 | 日本語の意味 | 用途 |
| --- | --- | --- |
| 진단하기 | 診断する | 選択した接続を調べる |
| IP 충돌 복구 | IP競合を修復 | 診断で対応可能とされた修復を試す |
| 변경 되돌리기 | 変更を元に戻す | アプリが変更した設定を復元 |
| 기록 폴더 | 記録フォルダー | 診断記録とバックアップを開く |

結果も韓国語です。意味が分からない場合は表示された文をそのまま添えて相談してください。

### Windowsの警告が表示された場合

デジタル署名がないため、発行元を確認できないという警告が出る場合があります。このリポジトリから直接取得したファイルか確認してください。「WindowsによってPCが保護されました」の画面で、出所を確認して実行する場合は**詳細情報 → 実行**を選べます。会社・学校の制限で実行できない場合は管理者に相談してください。セキュリティソフトを無効にしないでください。

## 5. 修復を試す

1. 診断が終わり、**IP 충돌 복구**が押せるか確認します。灰色のボタンは現在使えません。
2. オンライン作業やダウンロードを終えてください。修復中は一時的に接続が切れる場合があります。
3. **IP 충돌 복구**を押します。
4. Windowsから変更の許可を求められたら、今依頼した修復を進める場合に**はい**を押します。**Windows PowerShell**と表示されることがあります。管理者パスワードが分からない場合は管理者に相談してください。**いいえ**を選ぶと依頼した操作は実行しません。
5. 完了までアプリを閉じずに待ちます。
6. ブラウザーで普段使うサイトを開き、接続を確認します。

失敗したら繰り返し押さず、エラー文を確認して次の対処表を参照してください。

## 6. 変更を元に戻す

1. 対象の有線アダプターを選びます。
2. **변경 되돌리기**を押します。
3. 管理者権限の確認に応答し、完了まで待ちます。

以前の接続問題が再発する場合があります。復元できる記録がない場合などはボタンが灰色になります。その後に他の人やプログラムが設定を変えた場合、現在の設定を保護するため復元が拒否されることがあります。

## 7. 困ったとき

| 状況 | 対処 |
| --- | --- |
| `Engine.ps1`が見つからない | ZIP全体を再度展開し、EXEとPS1を同じフォルダーに置いてください。 |
| スクリプトのブロックや署名エラー | アプリを閉じ、元のZIPのプロパティでブロックを解除して新しいフォルダーに展開してください。管理対象PCでは管理者に相談してください。 |
| 有線アダプターが表示されない | LANケーブルやUSB LANアダプターの接続を確認してください。Wi-Fiは対象外です。 |
| 修復ボタンが灰色 | 診断完了まで待ちます。正常な接続や未対応の問題では修復できません。 |
| 修復後もつながらない | 結果、ケーブル、ルーターを確認します。他の機器も接続できなければ管理者や回線事業者に相談してください。 |
| アプリが開かない | WindowsであることとZIPを展開済みであることを確認し、エラー文を控えて相談してください。 |

## 8. 対応する問題と用語

**IPアドレス**はネットワーク内で機器を区別する住所のようなものです。2台が同じ住所を使うと**IP競合**が起こる場合があります。**DHCP**は通常ルーターが各機器に住所を自動で割り当てる機能です。

競合の修復では、アダプターを識別する値であるソフトウェア**MACアドレス**を変更し、別のDHCPアドレスの取得を試みます。DHCPアドレスを受け取れない問題では、選択した有線アダプターを再起動します。

ケーブル故障、回線障害、すべてのドライバー問題を解決するものではありません。ルーターの重複割り当ての原因自体も修正しません。再発する場合はルーターの割り当て設定や他の機器の手動アドレス設定を確認する必要があります。

固定IP（手動設定した住所）のアダプターは自動変更しません。Wi-Fi、ファイアウォール、DNSサーバー、ルーターの設定も変更しません。

## 9. 記録と削除

**기록 폴더**で記録と設定バックアップを開けます。保存先は`%LOCALAPPDATA%\EthernetHelper`です。記録は自動で外部に送信されません。

記録にはIP・MACアドレスやアダプター情報が含まれる場合があります。公開するときは不要な情報を削除してください。復元する可能性があればバックアップを保管してください。

削除するにはアプリを閉じ、展開したフォルダーを削除します。**削除だけではネットワーク設定は戻りません。** 戻したい場合は先に**변경 되돌리기**を使ってください。記録フォルダーは別に残ります。自動起動、予約タスク、常駐サービスはインストールしません。

## 10. 問い合わせ

[GitHub Issues](https://github.com/ksj0104/EthernetHelper/issues)の**New issue**から報告できます。投稿にはGitHubアカウントが必要です。

- 問題が起きたときの操作
- 表示されたエラー文（韓国語のままでも可）
- Windowsバージョン：**Windowsキー + R → `winver` → OK**
- 分かれば有線アダプターの型番

パスワードや未確認の診断記録をそのまま投稿しないでください。ソースからビルドする方は[開発者向けの説明](README.md#development)をご覧ください。
