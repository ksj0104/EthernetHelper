# 이더넷 연결 도우미 — 쉬운 사용 안내

[언어 선택](README.md) · [English](README.en.md) · [日本語](README.ja.md)

## 1. 어떤 프로그램인가요?

컴퓨터에 **랜선(인터넷 케이블)**을 꽂았는데 인터넷이 잘 안 될 때 연결을 점검하는 프로그램입니다. 고칠 수 있는 문제가 발견되면 복구 버튼을 사용할 수 있습니다.

처음 실행하면 진단부터 합니다. **진단은 네트워크 설정을 바꾸지 않습니다.** 복구 버튼을 눌러야 설정 변경을 시도합니다.

- Windows 10/11 PC용입니다. Mac이나 휴대폰에서는 실행되지 않습니다. 실제 PC 검증은 Windows 10 64비트에서 했으며 Windows 11은 추가 확인이 필요합니다.
- Wi-Fi(무선 인터넷) 복구 도구가 아닙니다. 랜선을 사용하는 연결이 대상입니다.
- 설치나 프로그래밍 지식은 필요하지 않습니다. Windows 구성 요소인 PowerShell 5.1과 .NET Framework 4.x를 사용합니다.
- 인터넷이 안 돼 다운로드할 수 없다면 다른 컴퓨터에서 ZIP을 받아 USB로 옮기세요.

## 2. 다운로드하기

1. **[여기를 눌러 Windows용 ZIP 다운로드](https://raw.githubusercontent.com/ksj0104/EthernetHelper/master/downloads/EthernetHelper-Windows.zip)**를 시작합니다. GitHub 로그인은 필요하지 않습니다.
2. 완료될 때까지 기다립니다. ZIP은 여러 파일을 하나로 묶은 압축파일입니다.
3. 키보드의 **Windows 키 + E**를 함께 눌러 파일 탐색기를 엽니다. 왼쪽에서 **다운로드**를 누릅니다.
4. `EthernetHelper-Windows.zip`을 찾습니다. 컴퓨터 설정에 따라 뒤의 `.zip`은 안 보일 수 있습니다.

GitHub의 `Code` 메뉴나 소스 파일을 하나씩 받을 필요는 없습니다.

## 3. 압축 풀기

1. 받은 ZIP 파일을 **마우스 오른쪽 버튼**으로 누르고 **속성**을 선택합니다.
2. **일반** 탭 아래에 **차단 해제**가 있으면 체크하고 **적용 → 확인**을 누릅니다. 없으면 그냥 **확인**을 누르고 진행합니다.
3. ZIP을 다시 우클릭하고 **모두 압축 풀기**를 선택합니다.
4. 저장 위치는 기본값 그대로 두고 **압축 풀기**를 누릅니다.
5. 새로 열린 폴더에 다음 파일이 있는지 확인합니다.

| 파일 | 하는 일 | 내가 할 일 |
| --- | --- | --- |
| `EthernetHelper.exe` | 프로그램을 여는 실행파일 | 더블 클릭해서 실행 |
| `Engine.ps1` | 진단·복구에 필요한 파일 | 실행파일 옆에 그대로 두기 |
| `README`로 시작하는 파일들 | 언어별 설명서 | 필요할 때 읽기 |

**ZIP 안에서 바로 실행하지 말고 먼저 압축을 푸세요.** `Engine.ps1`은 직접 실행할 필요가 없습니다. 실행파일만 다른 폴더로 옮기지 마세요.

## 4. 실행하고 진단하기

1. 압축을 푼 폴더에서 **EthernetHelper.exe**를 더블 클릭합니다. 확장자가 숨겨져 있으면 `EthernetHelper`로 보입니다.
2. 자동 진단이 끝날 때까지 기다립니다.
3. 유선 연결 선택 목록이 여러 개라면 랜선이 연결된 항목을 선택합니다. 어떤 항목인지 모르면 자세히 아는 사람에게 확인하세요.
4. 다시 확인하려면 **진단하기**를 누릅니다.
5. 화면의 결과와 안내를 읽습니다. 정상이라고 나오면 복구할 필요가 없습니다.

### Windows 실행 경고가 나와요

이 프로그램은 디지털 서명이 없어 게시자를 확인할 수 없다는 경고가 나올 수 있습니다. 위 저장소에서 직접 받은 파일인지 먼저 확인하세요. **Windows의 PC 보호** 화면에서 출처를 확인하고 실행하기로 했다면 **추가 정보 → 실행**을 선택할 수 있습니다. 회사·학교 정책으로 차단되거나 실행 버튼이 없으면 관리자에게 문의하세요. 보안 프로그램을 끄지 마세요.

## 5. 문제가 있을 때 복구하기

1. 진단이 끝나면 **IP 충돌 복구** 버튼을 사용할 수 있는지 확인합니다. 회색이면 현재 사용할 수 없다는 뜻입니다.
2. 온라인 작업이나 다운로드를 마무리합니다. 복구 중 인터넷이 잠시 끊길 수 있습니다.
3. **IP 충돌 복구**를 누릅니다.
4. Windows가 “이 앱이 디바이스를 변경하도록 허용하시겠어요?”라고 물으면, 방금 요청한 복구를 진행하려는 경우 **예**를 누릅니다. Windows PowerShell 이름으로 표시될 수 있습니다. 관리자 암호를 모르면 PC 관리자에게 요청하세요. **아니요**를 누르면 요청한 작업을 실행하지 않습니다.
5. 완료 안내가 나올 때까지 프로그램을 닫지 말고 기다립니다.
6. 브라우저에서 평소 사용하던 사이트를 열어 인터넷이 되는지 확인합니다.

실패하면 같은 버튼을 반복해서 누르기보다 오류 문구를 확인하고 아래 안내를 참고하세요.

## 6. 바뀐 설정 되돌리기

1. 프로그램에서 해당 유선 어댑터를 선택합니다.
2. **변경 되돌리기**를 누릅니다.
3. 관리자 권한 요청에 응답하고 완료될 때까지 기다립니다.

되돌리면 이전의 인터넷 문제가 다시 나타날 수 있습니다. 해당 연결에 사용 가능한 복원 기록이 없는 경우 등에는 버튼이 회색입니다. 이후 다른 사람이나 프로그램이 설정을 바꿨다면 현재 설정을 보호하기 위해 복원이 거부될 수 있습니다.

## 7. 자주 겪는 문제

| 상황 | 해볼 일 |
| --- | --- |
| `Engine.ps1`이 없다고 나와요 | ZIP 전체를 다시 압축 풀고 두 파일을 같은 폴더에 두세요. |
| 스크립트 차단이나 서명 오류가 나와요 | 프로그램을 닫고 원본 ZIP의 속성에서 차단을 해제한 뒤 새 폴더에 다시 압축을 푸세요. 회사·학교 PC는 관리자에게 문의하세요. |
| 유선 어댑터가 없다고 나와요 | 랜선과 USB 랜 어댑터 연결을 확인하세요. Wi-Fi는 대상이 아닙니다. |
| 복구 버튼이 회색이에요 | 진단이 끝날 때까지 기다리세요. 정상 연결이나 지원하지 않는 문제는 복구가 활성화되지 않습니다. |
| 복구 후에도 인터넷이 안 돼요 | 화면 안내, 랜선과 공유기 상태를 확인하세요. 다른 기기도 안 되면 공유기 관리자나 통신사에 문의하세요. |
| 프로그램이 안 열려요 | Windows PC인지, 압축을 풀었는지 확인하고 오류 문구를 적어 도움을 요청하세요. |

## 8. 무엇을 고칠 수 있나요?

- **IP 주소**는 네트워크에서 컴퓨터를 구분하는 주소입니다. 두 기기가 같은 주소를 사용하면 **IP 충돌**이 생길 수 있습니다.
- **DHCP**는 보통 공유기가 기기에 주소를 자동으로 나눠 주는 기능입니다.
- **MAC 주소**는 네트워크 어댑터를 구분하는 값입니다. 충돌 복구에서는 선택한 어댑터의 소프트웨어 MAC 주소를 바꿔 다른 DHCP 주소를 받도록 시도합니다.
- DHCP 주소를 받지 못하는 문제에서는 선택한 유선 어댑터를 재시작합니다.

랜선 고장, 통신사 장애, 모든 드라이버 문제를 해결하지는 못합니다. 공유기의 중복 주소 할당 원인 자체도 수정하지 않습니다. 반복되면 공유기의 주소 할당 설정과 다른 기기의 수동 주소 설정을 확인해야 합니다.

고정 IP(사람이 직접 정한 주소)를 쓰는 어댑터는 자동 변경하지 않습니다. Wi-Fi, 방화벽, DNS 서버와 공유기 설정도 변경하지 않습니다.

## 9. 기록 확인과 삭제

**기록 폴더**를 누르면 진단 기록과 설정 백업이 있는 폴더가 열립니다. 저장 위치는 `%LOCALAPPDATA%\EthernetHelper`입니다. 기록은 자동으로 외부에 업로드되지 않습니다.

기록에는 IP·MAC 주소와 어댑터 정보가 포함될 수 있습니다. 공개할 필요 없는 정보를 지운 뒤 공유하세요. 설정을 되돌릴 수 있도록 백업은 보관하세요.

삭제하려면 프로그램을 닫고 압축을 푼 프로그램 폴더를 삭제하면 됩니다. **삭제만으로 네트워크 설정이 되돌아가지는 않습니다.** 설정도 돌리려면 먼저 **변경 되돌리기**를 사용하세요. 기록 폴더는 별도로 남습니다. 자동 시작, 예약 작업, 상주 서비스는 설치하지 않습니다.

## 10. 도움 요청하기

[GitHub Issues](https://github.com/ksj0104/EthernetHelper/issues)의 **New issue**로 문제를 남길 수 있습니다. 작성에는 GitHub 로그인이 필요합니다.

- 어떤 작업을 하다가 문제가 생겼는지
- 화면에 나온 오류 문구
- Windows 버전: **Windows 키 + R → `winver` 입력 → 확인**
- 알 수 있다면 유선 어댑터 모델

비밀번호나 전체 진단 기록을 그대로 올리지 마세요. 소스를 수정하려는 분은 [개발자 안내](README.md#development)를 참고하세요.
